# Description

A mod for b1.7.3 that is a port of [Vendo's Grass Block Fix](https://github.com/VendoAU/GrassBlockFix)

The mod originally made for Risugami's ModLoader but due to some flaw with the way it modified, it has been move to JarModAgent

This mod is pretty much not really useful if you can't access the grass block item (which is normally unobtainable in this version)

Only require [JarModAgent](https://github.com/FarnGitHub/Farn_Minecraft_Mod_Collection/wiki/Unimined-JarModAgent-Installation)
